Данный проект представляет из себя оптимизированную версию базового блочного алгоритма шифрования "Кузнечик"

Ключевой особенностью является оптимизация на уровне одного блока. Это позволяет добиться (на мощных видеокартах) прироста скорости для режимов с зацеплением

Сам файл проводит базовое тестирование алгоритма, а также измерение времени работы на разных объемах данных для:
- ECB с последовательной обработкой блоков
- ECB с параллельной обработкой блоков
- CTR с последовательной обработкой блоков
- CTR с параллельной обработкой блоков
- CBC, OFB, CFB
